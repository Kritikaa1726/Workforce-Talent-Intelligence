# Workforce & Talent Intelligence – HR Analytics

## Project Overview
This project focuses on analysing workforce, recruitment, employee retention, and payroll data using Power BI and beginner-level SQL.

The objective is to understand workforce performance and transform HR data into meaningful insights that can support better HR and business decisions.

## Tools & Technologies
- Power BI
- DAX
- Microsoft Excel
- SQLSheet (Online SQLite Editor)

## Dashboard Features

The interactive Power BI dashboard includes:

- Active Employee Headcount
- New Hires and Exited Employees
- Average Employee Engagement
- Annual Payroll
- Recruitment Funnel
- Monthly Hiring Trends
- Department-wise Attrition
- Recruitment Source Analysis
- Department-wise Payroll
- Employee Engagement and Performance Analysis

## SQL Learning & Practice
Alongside Power BI, I have started learning SQL using SQLite.

My practice includes:
- SELECT and WHERE
- COUNT, SUM and AVG
- GROUP BY
- ORDER BY
- Basic HR data exploration

 The objective is to understand how SQL can be used to analyse HR data and support dashboard reporting.

The SQL file represents my current learning progress and is not a complete or advanced SQL solution.
